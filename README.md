# JobTracker

Serverlose PWA für die Bewerbungsverwaltung: Bewerbungen mit individuellen Status-Kategorien erfassen, per Tabelle oder Kanban-Board verwalten, Termine im Kalender planen und den Überblick über Erfolgsquote und Gehälter im Dashboard behalten. Alle Daten bleiben lokal im Browser (IndexedDB) - kein Server, kein Konto nötig.

Einfach `index.html` öffnen oder als installierbare PWA nutzen.
